# Регламент: скриншоты -> файл импорта

Этот процесс выполняется в отдельном диалоге. Его результат - один размеченный
`CSV` или `XLSX`, который загружается в сайт через вкладку `Импорт`.

## Что передавать агенту

- Папку со скриншотами одного варгейма.
- Название собственной гильдии: `Avengers`.
- Требование: перенести **все видимые строки всех сторон**, а не только Avengers.

## Что агент должен вернуть

1. `match_<yyyy-mm-dd>_<location>_players.csv` в UTF-8 с разделителем `;`.
2. При желании такую же таблицу в `.xlsx` с первым листом `Import`.
3. Короткое сообщение о покрытии: `видно строк / заявлено участников`.
4. Список сомнительных строк, если имя, число или иконка не читаются уверенно.

Не надо возвращать скриншоты в сайт и не надо встраивать изображения в файлы данных.

## Обязательная таблица

Одна строка = один игрок в одном матче. Колонки строго такие:

| Колонка | Смысл | Правило |
| --- | --- | --- |
| `match_id` | стабильный ID матча | `yyyy-mm-dd-location-slug` |
| `date` | дата боя | `dd.mm.yyyy` |
| `location` | локация | как на экране; если не видна, указать `Не указано` |
| `title` | подпись матча | `Avengers vs <основной соперник>` |
| `primary_guild` | наша гильдия | всегда `Avengers` |
| `participants_shown` | сколько строк перенесено | одно и то же число на всех строках матча |
| `participants_reported` | сколько участников указано в UI | одно и то же число на всех строках матча |
| `source_document` | источник | имя CSV/XLSX или папки скриншотов |
| `rank` | место игрока | целое число из таблицы |
| `player_name` | имя | ровно как на скрине |
| `guild` | гильдия | ровно как на скрине |
| `team` | команда | `Yellow`, `Red`, `Синяя команда`, `Красная команда`, пусто если не видно |
| `kills` | убийства | колонка `Defeat` / `Убийства`, только целое число |
| `assists` | помощь | целое число |
| `damage` | нанесенный урон | целое число без пробелов |
| `damage_taken` | полученный урон | целое число без пробелов |
| `healing` | лечение | целое число без пробелов |
| `loadout` | класс по двум иконкам | значение из словаря ниже |

## Словарь классов

Записывать полное русское имя, без сокращений:

| Иконки оружия | Значение `loadout` |
| --- | --- |
| Кинжал + Копье | `Кинжал + Копье` |
| Лук + Кинжал | `Лук + Кинжал` |
| Арбалет + Двурук | `Арбалет + Двурук` |
| Лук + Стаф | `Лук + Стаф` |
| Арбалет + Кинжал | `Арбалет + Кинжал` |
| Щит + Двурук | `Щит + Двурук` |
| Стаф + Кинжал | `Стаф + Кинжал` |
| Копье + Двурук | `Копье + Двурук` |
| Лук + Ванда | `Лук + Ванда` |
| Стаф + Ванда | `Стаф + Ванда` |
| Кинжал + Двурук | `Кинжал + Двурук` |

Если встретилась новая комбинация, записать понятное полное имя по иконкам и
отдельно сообщить, что это новый класс.

## Порядок переноса

1. Определить число участников в верхней части окна (`participants_reported`).
2. Пройти скрины по рангу сверху вниз.
3. Для каждого видимого ранга перенести все числовые поля и обе иконки оружия.
4. Не включать закрепленную строку `Мой вклад`, если та же строка уже есть в ранге.
5. Не додумывать пропущенные места: если ранги не попали на скрины, они отсутствуют в файле.
6. Выставить `participants_shown` равным количеству реально внесенных строк.
7. Проверить, что `rank` внутри матча не повторяется.

## Контроль качества перед выдачей

- В файле присутствуют обе стороны и союзные кланы.
- Числа записаны без `K`, `млн` и разделителей тысяч.
- `participants_shown` равен числу строк матча.
- Ни у одной строки не пусты `match_id`, `rank`, `player_name`, `guild` и `loadout`.
- Один и тот же игрок может быть в разных матчах; это нормально.
- Если игрок сменил класс между боями, новый `loadout` записывается по текущему скрину.

## Готовый промпт для отдельного диалога

```text
Ты агент подготовки импорта для сайта аналитики варгеймов.
Получишь папку со скриншотами таблицы результатов Throne and Liberty.

Задача:
1. Перенеси ВСЕ видимые строки всех гильдий в таблицу, не только Avengers.
2. Для каждой строки распознай две иконки оружия и запиши полный loadout по словарю.
3. Не включай закрепленную строку "Мой вклад", если игрок уже присутствует в ранжированной таблице.
4. Не выдумывай строки, которых нет на скриншотах.
5. Верни CSV UTF-8 с разделителем ";" и, если удобно, XLSX с теми же колонками.

Колонки строго:
match_id;date;location;title;primary_guild;participants_shown;participants_reported;source_document;rank;player_name;guild;team;kills;assists;damage;damage_taken;healing;loadout

primary_guild всегда Avengers.
В числах не использовать K, млн и пробелы: только целые значения.
В конце напиши покрытие вида "внесено N из M строк" и перечисли сомнительные чтения.
```
