# Avengers Battle Intelligence

Сайт аналитики битв гильдий Throne and Liberty. Сайт работает по размеченным
таблицам, а обработка скриншотов вынесена в отдельный процесс.

## Запуск

```powershell
npm install
npm run dev
```

## Данные

- Импортированы три матча: `23.05.2026` и два боя `25.05.2026`.
- Внесено `286` читаемых строк из `300`: `Carmine Forest` - `90/96`, `Shattered Temple` - `96/96`, `Выжженные земли` - `100/108`.
- Классы вручную размечены по иконкам оружия в видимых строках; порядок оружия в паре не считается отдельным классом.
- Базовый источник сайта: `src/data/matches.csv`. Изображения не используются в расчетах и не подгружаются на сайт.

## Импорт

- Вкладка `Импорт` принимает `.csv` или `.xlsx` с нормализованными строками игроков только для локального предпросмотра в текущем браузере.
- Для нового матча используется шаблон `import-templates/wargame_import_template.csv` или `.xlsx`.
- Повторный `match_id` заменяет соответствующий локально проверяемый матч; такой импорт не меняет публичный сайт для остальных пользователей.
- Полный регламент для отдельного диалога, который размечает скриншоты: `docs/SCREENSHOT_TO_IMPORT_GUIDE.md`.

## Публикация

Публичный источник данных - `src/data/matches.csv`. Рабочий процесс обновления:

1. Передать скриншоты битвы в Codex.
2. Codex извлекает показатели, проверяет структуру и дописывает или заменяет матч в `src/data/matches.csv`.
3. Codex собирает сайт и отправляет изменения в GitHub-репозиторий.
4. Cloudflare Pages автоматически публикует новую сборку по постоянной ссылке вида `https://<название>.pages.dev/`.

Настройки проекта для Cloudflare Pages:

```text
Framework preset: Vite
Build command: npm run build
Build output directory: dist
```

При первой настройке нужен GitHub-репозиторий, подключенный к Cloudflare Pages. После подключения каждое обновление ветки публикации пересобирает сайт автоматически.

## Аналитика

- На странице матча Avengers и основной клан соперников с союзниками выведены параллельно.
- Экран `Игроки` содержит таблицу с фильтрами класса/роли и сортировкой.
- Экран `Аналитика` содержит таблицу оценки игроков с фильтром по иконкам класса, средними киллами/уроном/полученным уроном/лечением и цветными сигналами слабого звена.
- Индекс класса сравнивает игрока со средним и лучшим игроком той же комбинации оружия: для ДД - киллы 65%, урон 25%, помощь 10%; для поддержки - отхил 100%; для фронтлайна - полученный урон 50%, киллы 30%, урон 20%.
- Сейчас в окне доступны три матча из десяти; устойчивость оценки улучшилась, но для кадровых выводов все еще нужны дополнительные матчи и статистика смертей.
